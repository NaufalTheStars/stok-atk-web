TENTANG SISTEM

Judul: Sistem Informasi Pendataan Stok Alat Tulis Kantor Berbasis Web
Cocok karena alur sederhana dan jelas, sudah ada database, proses perhitungan, laporan.
  1. Pilih barang - Kasir memilih produk
  2. Menghitung total otomatis - Harga x Jumlah. Contoh Pensil 2x2000=4000, Buku 3x5000=15000 Total 19000
  3. Input pembayaran & hitung kembalian
  4. Menyimpan data transaksi (No transaksi, tanggal, nama barang, jumlah, total harga, nama kasir)
  5. Mengurangi stok otomatis - 50 jadi 47
  6. Membuat laporan penjualan per hari/bulan

Alur: Data Barang -> Pelanggan Membeli -> Kasir Input Transaksi -> Stok Berkurang -> Laporan Penjualan
